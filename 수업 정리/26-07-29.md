## 1. MoveIt 실습

`moveit_test.py`는 `MoveItPy`를 이용하여 로봇팔의 이동 경로를 계획하고 실행하는 코드이다.

```python
moveit = MoveItPy(
    node_name="open_manipulator_moveit_py"
)

arm = moveit.get_planning_component("arm")
gripper = moveit.get_planning_component("gripper")
```

현재 상태를 시작 위치로 설정하고, 미리 정의된 자세까지 이동 경로를 계획한다.

```python
component.set_start_state_to_current_state()
component.set_goal_state(
    configuration_name=configuration_name
)

plan_result = component.plan()
```

계획에 성공하면 지정된 Controller로 경로를 실행한다.

```python
moveit.execute(
    plan_result.trajectory,
    controllers=[controller_name]
)
```

실행 순서:

```text
arm을 home 자세로 이동
    ↓
gripper 열기
    ↓
gripper 닫기
    ↓
gripper 다시 열기
```

실행:

```bash
ros2 run tf2_basic moveit_test
```

## 2. Move Manipulator Action

`move_manipulator_action.py`는 Action을 이용하여 로봇팔 관절과 그리퍼를 제어한다.

사용하는 Action Server:

```text
/arm_controller/follow_joint_trajectory
/gripper_controller/gripper_cmd
```

Action Client 생성:

```python
self.joint_client = ActionClient(
    self,
    FollowJointTrajectory,
    "/arm_controller/follow_joint_trajectory"
)

self.gripper_client = ActionClient(
    self,
    GripperCommand,
    "/gripper_controller/gripper_cmd"
)
```

1.5초마다 두 개의 관절 자세를 번갈아 전송한다.

```text
첫 번째 관절 자세 + 그리퍼 열기
    ↓
두 번째 관절 자세 + 그리퍼 닫기
    ↓
반복
```

팔에는 `FollowJointTrajectory.Goal`을 전송한다.

```python
goal = FollowJointTrajectory.Goal()
goal.trajectory.joint_names = [
    "joint1",
    "joint2",
    "joint3",
    "joint4"
]
goal.trajectory.points.append(point)

self.joint_client.send_goal_async(goal)
```

그리퍼에는 `GripperCommand.Goal`을 전송한다.

```python
goal = GripperCommand.Goal()
goal.command.position = position
goal.command.max_effort = max_effort
```

Action 결과는 다음 상태로 구분한다.

```text
SUCCEEDED
ABORTED
CANCELED
```

실행:

```bash
ros2 run tf2_basic move_manipulator_action
```

## 3. Teach Manipulator

Teach Manipulator는 로봇팔의 토크를 끈 뒤, 사용자가 손으로 만든 자세를 저장하는 실습이다.

토크를 끄는 Service:

```text
/dynamixel_hardware_interface/set_dxl_torque
```

```python
request = SetBool.Request()
request.data = False
```

토크가 꺼지면 로봇팔을 손으로 움직일 수 있다.

`/joint_states`를 구독하여 다음 값을 저장한다.

```text
joint1
joint2
joint3
joint4
gripper_left_joint
```

키보드 조작:

```text
SPACE : 현재 로봇팔과 그리퍼 자세 저장
Q     : 저장 후 종료
H     : 사용 방법 표시
```

저장되는 한 단계의 내용:

```yaml
positions:
  - joint1 값
  - joint2 값
  - joint3 값
  - joint4 값
gripper: 그리퍼 위치
duration: 이동 시간
pause: 동작 후 대기 시간
```

기본 버전 실행:

```bash
ros2 run tf2_basic teach_manipulator
```

기본 버전은 현재 폴더에 다음 파일을 생성한다.

```text
teach_data.yaml
```

확장 버전 실행:

```bash
ros2 run tf2_basic teach_manipulator_T1
```

확장 버전은 홈 폴더에 시간 정보가 포함된 파일을 만든다.

```text
~/recorded_dance_날짜_시간.yaml
```

예시:

```text
~/recorded_dance_20260728_103000.yaml
```

> 토크가 꺼진 순간 로봇팔이 처질 수 있으므로 반드시 손으로 로봇팔을 지지해야 한다.

## 4. Play Recorded

`play_recorded_dance.py`는 Teach Manipulator에서 저장한 YAML 동작을 다시 실행하기 위한 노드이다.

다음 위치에서 녹화 파일을 찾는다.

```text
사용자 홈 폴더
현재 실행 폴더
tf2_basic 패키지의 data 폴더
```

검색하는 파일 이름:

```text
recorded_dance*.yaml
```

여러 파일이 있으면 가장 최근에 수정된 파일을 선택한다.

```python
return max(
    candidates,
    key=candidates.get
)
```

선택한 YAML 파일에 저장된 다음 정보를 이용하여 로봇팔을 움직인다.

```text
관절 위치
그리퍼 위치
이동 시간
동작 사이의 대기 시간
```

실행:

```bash
ros2 run tf2_basic play_recorded_dance
```

재생 전 확인사항:

```text
모터 토크가 ON 상태인지 확인
로봇팔 주변의 장애물 제거
저장된 관절 위치가 실제 로봇의 제한 범위 안인지 확인
```

## 5. Teach와 Play 전체 흐름

```text
OpenManipulator Controller 실행
    ↓
teach_manipulator_T1 실행
    ↓
토크 OFF 확인
    ↓
로봇팔을 손으로 원하는 자세로 이동
    ↓
SPACE를 눌러 자세 저장
    ↓
다음 자세로 이동 후 SPACE 반복
    ↓
Q를 눌러 YAML 저장 및 종료
    ↓
모터 토크 다시 ON
    ↓
로봇팔 주변 정리
    ↓
play_recorded_dance 실행
    ↓
저장된 자세 순서 재생
```

## 6. 각 제어 방식 비교

| 실습 | 제어 방법 | 특징 |
|---|---|---|
| `moveit_test` | MoveIt 경로 계획 | 목표 자세까지 경로를 계산한 후 실행 |
| `move_manipulator_action` | Controller Action | 지정한 관절값과 그리퍼값을 직접 Goal로 전송 |
| `teach_manipulator` | 수동 Teaching | 손으로 만든 자세를 YAML로 저장 |
| `play_recorded_dance` | YAML 재생 | 저장된 관절 및 그리퍼 동작을 다시 실행 |
